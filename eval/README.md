# Evaluation data

No real shelf photos are bundled in v1 — none were supplied.
Add Olly's staged shelf photos here with a hand-counted ground_truth.csv:
image,class,manual_count

Ground truth is the note Olly writes per shot (shelf name, total count,
count per visible type, hidden items noted separately). Without it, a clip
cannot be scored.
